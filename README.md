# SelletBot
SellerBot MVP es un bot conversacional para WhatsApp que automatiza la ventas, carrito de compras, catálogo con imágenes, integración con Mercado Pago y registro avanzado de interacciones. Incluye logging detallado, manejo de botones y mensajes enriquecidos, y está listo para personalizarse y escalarse en proyectos de e-commerce conversacional.
